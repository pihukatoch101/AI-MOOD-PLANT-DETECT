# AI-MOOD-PLANT-DETECT
A Jupyter Notebook-based Artificial Intelligence project that applies Machine Learning and Data Processing techniques to analyze visual/environmental inputs for detecting plant health and human emotional contexts.

## 🧠 Project Overview
This project showcases the intersection of Software Engineering and Artificial Intelligence. It explores image dataset processing and feature extraction models to recognize patterns associated with human moods and corresponding plant care recommendations.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Environment:** Jupyter Notebook
* **Core Packages:** NumPy, Pandas, Matplotlib (for data visualization and array formatting)
* **AI/ML Concepts:** Feature engineering, image classification patterns, and predictive analytics.

## 📈 Future Scope
* Enhancing model accuracy using Deep Learning frameworks (TensorFlow / PyTorch).
* Deploying the backend script as an interactive web application.
